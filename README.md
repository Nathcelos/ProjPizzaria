#  Sistema de Pizzaria

Sistema desenvolvido em Java com integração ao banco de dados MySQL para gerenciamento de uma pizzaria.

---

##  Status do Projeto

 Projeto em desenvolvimento.

---

##  Objetivo do Software

O objetivo do sistema é auxiliar no gerenciamento de uma pizzaria, facilitando o controle de clientes, funcionários, pedidos, estoque e pagamentos.

O software foi desenvolvido para tornar o atendimento e a administração mais organizados e eficientes.

---

##  Funcionalidades

- Cadastro de clientes
- Cadastro de funcionários
- Sistema de login
- Controle de usuários
- Gerenciamento de pedidos
- Controle de estoque
- Cadastro de produtos/cardápio
- Controle de pagamentos
- Relatórios do sistema

---

##  Tecnologias Utilizadas

- Java
- MySQL
- Apache NetBeans IDE
- MySQL Workbench
- Git
- GitHub

---

##  Banco de Dados

O sistema utiliza banco de dados MySQL para armazenamento das informações e gerenciamento dos dados da pizzaria.

---

##  Como Executar o Projeto

1. Clonar o repositório
2. Abrir o projeto no Apache NetBeans
3. Configurar a conexão com o MySQL
4. Executar o script SQL do banco de dados
5. Rodar o projeto

---

##  Sobre o Projeto

Projeto desenvolvido para a disciplina de Projeto Integrador, com foco em desenvolvimento Java, integração com banco de dados e utilização de versionamento com Git e GitHub.
